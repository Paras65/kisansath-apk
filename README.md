# 🌾 किसान साथी (Kisan Saathi) - फसल से लेकर बिक्री तक (PWA & TWA)

**किसान साथी** एक आधुनिक, मोबाइल-फर्स्ट **Progressive Web App (PWA)** और **Trusted Web Activity (TWA)** है, जो किसानों के लिए **बुआई से लेकर फसल बिक्री तक** की सभी समस्याओं का ऑल-इन-वन (All-in-One) डिजिटल समाधान प्रदान करता है।

---

## 🌟 प्रमुख विशेषताएं (Core Modules)

### 1. 🚜 फसल चक्र के 6 चरण (Seed to Market Journey)
* **चरण 1: खेत तैयारी व मृदा स्वास्थ्य:** मिट्टी परीक्षण, pH मान (6.0-7.0) और ग्रीष्मकालीन गहरी जुताई।
* **चरण 2: बीज चयन व बीजोपचार:** प्रमाणित किस्में और ट्राइकोडर्मा / बाविस्टिन से बीजोपचार।
* **चरण 3: संतुलित खाद प्रबंधन:** यूरिया, डीएपी, पोटाश और जिंक का सही समय और चरणबद्ध खुराक।
* **चरण 4: फसल सुरक्षा व रोग निदान:** कीट-रोग पहचान, जैविक व रासायनिक उपचार।
* **चरण 5: कटाई व सुखाना:** सही नमी (14-17%) पर कटाई व भंडारण।
* **चरण 6: मंडी भाव व सरकारी बिक्री:** छत्तीसगढ़ कृषक उन्नति योजना (₹3,100/क्विंटल) एवं टोकन तुंहर हाथ।

### 2. 🔬 एआई फसल डॉक्टर (Crop Doctor & Photo Diagnosis)
* **फोटो डायग्नोसिस:** फोन कैमरे से रोगग्रस्त पत्ती की फोटो लें या गैलरी से अपलोड करें; एआई तुरंत रोग की पहचान करता है।
* **लक्षण फिल्टर:** पत्ती पर धब्बे, तना सूखना, भूरा माहू (BPH), उकठा, पत्ता मरोड़ आदि।
* **उपचार:** देशी/जैविक उपाय (नीम अर्क, ट्राइकोडर्मा) तथा सटीक रासायनिक दवा व छिड़काव खुराक।
* **🔊 आवाज में सुनें (Voice Assistance):** कम पढ़े-लिखे या बुजुर्ग किसानों के लिए हिंदी में बोलकर सुनाने की सुविधा (Web Speech API)।

### 3. 🧮 स्मार्ट कैलकुलेटर व सरकारी योजनाएं
* **खाद कैलकुलेटर (Fertilizer Calculator):** रकबा (एकड़) डालते ही यूरिया, DAP, पोटाश और जिंक की कुल मात्रा (किलो व बोरियों में) और समय-सारिणी।
* **धान ₹3,100 कैलकुलेटर (CG Krishak Unnati):** 21 क्विंटल/एकड़ के नियम से अधिकतम उपार्जन मात्रा, कुल आय, MSP हिस्सा (@₹2300) और बोनस हिस्सा (@₹800)।
* **सरकारी पोर्टल्स सीधा लिंक:**
  * टोकन तुंहर हाथ (Token Tuhar Hath)
  * एग्री-स्टैक / किसान रजिस्ट्री (Agri-Stack CGFR)
  * भुइयां (Bhuiyan B1 / Khasra)
  * सौर सुजला योजना (क्रेडा 3HP/5HP सोलर पंप)
  * पीएम-किसान सम्मान निधि (₹6,000 वार्षिक)
  * प्रधानमंत्री फसल बीमा योजना (PMFBY)

### 4. 🏪 लाइव मंडी भाव व सीधा खेत से व्यापार (Mandi & Marketplace)
* रायपुर, बिलासपुर, धमतरी, राजनांदगांव, कवर्धा, भाटापारा, जगदलपुर मंडियों के लाइव भाव।
* न्यूनतम, अधिकतम और मॉडल भाव एवं पिछले दिन से अंतर (+ / -)।
* **सीधा क्रेता-विक्रेता मंच:** किसान सीधे अपनी फसल (जैसे सुगंधित धान, चना, सब्जियां) बेचने हेतु लिस्टिंग डाल सकते हैं।

### 5. 🚜 कस्टम हायरिंग (मशीन रेंटल) व किसान चौपाल
* ट्रैक्टर + रोटावेटर, कंबाइन हार्वेस्टर, लेजर लेवलर और कृषि ड्रोन स्प्रेयर का किराया व संचालक संपर्क।
* **किसान चौपाल:** साथी किसानों और कृषि वैज्ञानिकों से सवाल-जवाब।
* **मेरी फसल डायरी:** अपनी बुआई तारीख दर्ज करके अगली खाद व सिंचाई का रिमाइंडर पाएं।

## 📱 PWA (Progressive Web App) की खूबियां

* **ऑफ़लाइन सपोर्ट (Offline Ready):** खेत में इंटरनेट न होने पर भी सर्विस वर्कर (`sw.js`) ऐप को चलाता है।
* **होमस्क्रीन पर इंस्टॉल:** 1-क्लिक में मोबाइल पर नेटिव ऐप की तरह इंस्टॉल होता है (`manifest.json`)।
* **लो-एंड फोन्स पर सुपर-फास्ट:** बिना किसी लैग के 60fps स्मूथ परफॉर्मेंस।

## 🤖 TWA (Trusted Web Activity) - Android APK / Play Store

इस ऐप को Google Play Store पर असली Android ऐप के रूप में पब्लिश करने के लिए TWA फाइल्स पहले से तैयार हैं:
* `.well-known/assetlinks.json` - Google Digital Asset Links सत्यापन
* `twa/twa-manifest.json` - Bubblewrap CLI कॉन्फ़िगरेशन
* `twa/TWA_BUILD_GUIDE.md` - 1-क्लिक में APK / AAB बनाने की पूरी गाइड

### त्वरित APK निर्माण (Quick Build with Bubblewrap):
```bash
npm install -g @bubblewrap/cli
cd twa
bubblewrap init --manifest=https://your-domain.web.app/manifest.json
bubblewrap build
```

## ⚙️ शून्य कोड परिवर्तन माइग्रेशन (Zero-Code Change Migration via .env)

यह सम्पूर्ण एप्लिकेशन **पर्यावरण चर (Environment Variables - `.env`)** द्वारा संचालित है। भविष्य में राज्य बदलने, नई दरें लागू करने या नए सरकारी पोर्टल जोड़ने के लिए **कोड में 1 लाइन भी बदलने की आवश्यकता नहीं है**।

केवल अपनी `.env` फाइल में मान बदलें:

```env
# 1. राज्य व ब्रांडिंग बदलना (उदा. मध्य प्रदेश या उत्तर प्रदेश हेतु)
VITE_STATE_NAME="मध्य प्रदेश"
VITE_DEFAULT_DISTRICT="इंदौर"

# 2. नए सत्र की धान दरें व नियम बदलना
VITE_PADDY_TOTAL_RATE=3200
VITE_PADDY_MSP_RATE=2350
VITE_PADDY_BONUS_RATE=850
VITE_PADDY_MAX_QUINTALS_PER_ACRE=25

# 3. नए सरकारी पोर्टल URL सेट करना
VITE_PORTAL_AGRISTACK_URL="https://your-state-agristack.gov.in/"
VITE_PORTAL_TOKEN_URL="https://your-state-token.gov.in/"
VITE_PORTAL_BHUIYAN_URL="https://your-state-landrecords.gov.in/"

# 4. बैकएंड API जोड़ना
VITE_WEATHER_API_URL="https://api.your-weather.com/"
VITE_MANDI_API_URL="https://api.your-mandi.com/"
```
बदलने के बाद तुरंत `npm run build` करें, पूरा एप्लिकेशन नए राज्य और दरों के साथ स्वतः तैयार हो जाएगा!
